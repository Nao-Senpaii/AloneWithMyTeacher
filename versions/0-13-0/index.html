Alone With My Teacher

Version 0.13.0

Hello! 💖

We are pleased to announce that after several months of development, we can finally show you the first part of Chapter 2 of Alone With My Teacher.

We've included lots of features we think you'll enjoy, and we're constantly coming up with and implementing new ideas to make sure you have a great time while you play.

Some of these features include:

  • Added 1/4 of Chapter 2.
  • Animated intro.
  • Animated main menu.
  • Fixed lag when opening the gallery.
  • You can now choose the protagonist's name.
  • Chapter selection menu.
  • Added new voice lines for Ruby.
  • Edited the UI buttons to make them collapsible and hide them during gameplay.
  • Added the credits screen.
  • Added 24 new illustrations.
  • Added 25 new vignettes.
  • Added a new background.
  • Fixed the colors of the previous backgrounds.
  • Edited the entire game UI.

Future updates will follow this model: relatively large updates released less frequently. I know the game is still quite short (a common complaint), but art and programming take time, and I don't want to create lazy art. I hope that with the upcoming updates this year, the game will have a length that satisfies players. If you'd like to support this project, I invite you to check out the Patreon, where you can get early access to updates.

We hope you’ll stick with us to continue following the development of Alone With My Teacher up close. Please feel free to share any suggestions or report any errors or bugs.

Without further ado, we’d like to thank you very much for your support with every update.
